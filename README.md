# Wace RP Launcher

Лаунчер ролевого сервера Wace RP. Он сам ставит Java 17, Minecraft 1.20.1, Forge и сборку модов
сервера, обновляет их и подключает к игре.

## Как начать играть (ЗБТ)

1. Подключитесь к сети Radmin VPN проекта.
2. Скачайте `WaceRP-Launcher-Setup.exe` в разделе [Releases](../../releases).
3. Запустите установщик. Windows SmartScreen может показать предупреждение: нажмите
   «Подробнее», затем «Выполнить в любом случае».
4. Введите ник и нажмите «Играть». Первый запуск скачивает около 1 ГБ, следующие — только
   изменения.
